# Website đặt vé xem phim

## Cài đặt các phần mềm cần thiết và cách cài các thành phần phụ thuộc (chỉ cần 1 lần tính từ khi clone dự án)

Trước khi chạy được trang web, cần phải cài phần mềm sau:

- NodeJS: [Tải ở đây](https://nodejs.org/en)
- Bun: [Tải ở đây](https://bun.com/)

Rồi mở dự án này và chạy lệnh sau

```bash
bun install
```

## Trong quá trình phát triển

Sau khi chạy xong thì mọi thư viện phụ thuộc đã được cài vào dự án, trong khi đang phát triển, ở Terminal rồi chạy lệnh sau

```bash
bun run dev
```
